# E-Commerce Sales & Customer Behavior SQL Analysis

A collection of analytical SQL queries designed to extract revenue, order trends, and customer retention metrics from an e-commerce database.

## Key Analytical Insights
- Calculated Monthly Recurring Revenue (MRR) and month-over-month sales growth.
- Identified high-value customers using customer lifetime value (CLV) aggregation.
- Rank-ordered top-performing product categories per region using window functions.

## SQL Techniques Applied
- Multi-table `INNER JOIN` and `LEFT JOIN` operations.
- Aggregate functions (`SUM`, `AVG`, `COUNT`) with `GROUP BY` and `HAVING`.
- Window Functions (`ROW_NUMBER()`, `DENSE_RANK()`, `SUM() OVER()`).
- Common Table Expressions (CTEs) for modular query execution.
